# 同花顺股票交易系统 

`xiadan_gushi.in.py` 是一个 Windows 单文件交易页面。它连接本机已启动的同花顺交易客户端，通过客户端内置的隐藏命令发送买入、卖出、撤单等指令。页面和交易执行都运行在同一台 Windows 电脑上。

> **该测试会发生真实委托，请务必确认真实意图或使用模拟券商账号。** 委托提交成功不等于成交，请以交易客户端中的委托、成交和持仓记录为准。

## 运行条件

- Windows 电脑，已安装并登录同花顺交易客户端。
- Python 3.10 或更新版本。不依赖任何其他库。
- 程序须与交易客户端运行在同一 Windows 登录会话中。仅把交易接口程序放在其他服务器上，不能操作访问者电脑里的交易客户端。

## 启动

下载 `xiadan_gushi.in.py`，在该文件所在目录打开 PowerShell 或命令提示符。本机使用建议运行：

```powershell
py -3 xiadan_gushi.in.py --host 127.0.0.1 --port 8765
```

程序会自动打开 `http://127.0.0.1:8765/`。若已占用 8765 端口，可以通过 `--port` 指定其他端口；加入 `--no-open` 可禁止自动打开浏览器。程序启动后会自动尝试连接交易客户端，客户端稍后启动时也会继续重试；页面上的“连接交易系统”按钮可立即重试。

直接运行 `py -3 xiadan_gushi.in.py` 时，当前程序默认监听 `0.0.0.0:8765`，同一网络中的设备也可能访问该页面。需要局域网调试时可显式使用：

```powershell
py -3 xiadan_gushi.in.py --host 0.0.0.0 --port 8765
```

这个页面没有用户登录机制。允许局域网访问前，请确认网络和 Windows 防火墙的访问范围；日常本机使用请指定 `--host 127.0.0.1`，不要把端口直接开放到公网，他会真实的给你的券商下单！！！！！

## 页面功能

| 功能 | 说明 |
| --- | --- |
| 买入 / 卖出 | 输入方向、6 位证券代码、价格（支持指定价格、买入价1～5、卖出价1～5、涨停价、跌停价等参数）、每笔数量。 |
| 批量委托 | 页面允许 1–20 笔相同委托；程序用 `;` 拼成一条命令，一次写入并回车。 |
| 撤单 | 支持全部、最近一笔、买入、卖出、按证券代码、按合同号撤单。 |


数量框支持正整数，以及程序接受的 `all`、`money:<金额>`、`position:<比例>` 格式。价格可填正数或页面支持的同花顺价格关键字。发送委托、撤单或原始命令前，均须勾选确认框。

批量返回中的“已确认 N/M 笔委托”表示页面在本次返回中解析到了 N 个合同号，不表示 N 笔已经成交。若返回信息不完整，应先在交易客户端核对真实委托记录，再决定后续操作。

## 发布与隐私

本工具依赖同花顺客户端；客户端版本变化可能导致连接或回包解析失效。修改版本后，请先在模拟券商账号中验证，再用于真实委托。
